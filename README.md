# Chá Revelação — Evelyn & Luiz

Convite digital responsivo para celular e computador.

## Estrutura

- `index.html` — estrutura e conteúdo do convite
- `style.css` — visual, responsividade e animações
- `script.js` — contagem regressiva, máscara de WhatsApp, animações e formulário
- `config.js` — configuração futura do Supabase
- `supabase.sql` — tabela e política para confirmações

## Como abrir

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.
4. O convite funciona visualmente mesmo sem o Supabase configurado.
